# Блок 2. Группы и их строение

## Вопрос 8. Алгебраические операции, алгебры. Группы, подгруппы, теорема Лагранжа.

**Суть на пальцах**: Бинарная операция берёт два элемента множества и выдаёт третий. Если операция ассоциативна, есть нейтральный элемент и у каждого элемента есть обратный, получается группа. Вся криптография с открытым ключом живёт в группах и кольцах: протокол Диффи и Хеллмана работает в $\mathbb{Z}_p^*$, эллиптические кривые работают в группе точек кривой, RSA считает в кольце $\mathbb{Z}_n$, где нужны сразу сложение, умножение и обратимость по модулю. Порядок элемента это размер порождаемой им подгруппы, и именно от порядка зависит, годится ли элемент как генератор ключа.

**Определения**:
- Бинарная (двуместная) операция на множестве $A$: отображение $*:A\times A\to A$, то есть каждой упорядоченной паре $(a,b)$ сопоставлен элемент $a*b\in A$ (замкнутость входит в определение операции).
- Свойства операции $*$: ассоциативность $a*(b*c)=(a*b)*c$; коммутативность $a*b=b*a$; нейтральный элемент $e$: $a*e=e*a=a$; обратный элемент к $a$: такой $a^{-1}$, что $a*a^{-1}=a^{-1}*a=e$; идемпотентность $a*a=a$; для двух операций ещё дистрибутивность: $a*(b+c)=a*b+a*c$ и $(b+c)*a=b*a+c*a$.
- Алгебра: множество (носитель) с фиксированным набором операций и аксиом. Типы по «силе» аксиом:
  - полугруппа: множество с ассоциативной бинарной операцией;
  - моноид: полугруппа, в которой есть нейтральный элемент;
  - группа: моноид, в котором у каждого элемента есть обратный;
  - абелева группа: группа с коммутативной операцией;
  - кольцо: $(R,+,\cdot)$, где $(R,+)$ абелева группа, $(R,\cdot)$ полугруппа и выполнена дистрибутивность; кольцо с единицей: есть нейтральный по умножению; коммутативное кольцо: умножение коммутативно;
  - поле: коммутативное кольцо с единицей, в котором каждый ненулевой элемент обратим (то есть $(K\setminus\{0\},\cdot)$ абелева группа).
- Группа $(G,*)$: (G1) ассоциативность; (G2) существует $e\in G$ с $e*a=a*e=a$; (G3) для каждого $a$ существует $a^{-1}$ с $a*a^{-1}=a^{-1}*a=e$. Группа абелева (коммутативна), если дополнительно $a*b=b*a$.
- Порядок группы $|G|$: число элементов. Порядок элемента $\operatorname{ord}(a)$: наименьшее $n>0$ с $a^n=e$ (если такого нет, порядок бесконечен).
- Обозначения: аддитивная запись ($+$, нуль $0$, противоположный $-a$) обычно для абелевых групп, мультипликативная ($\cdot$, $e$ или $1$, $a^{-1}$) для произвольных.

**Теоремы и формулы**:
- Следствия аксиом: нейтральный элемент единствен; обратный единствен; закон сокращения: $a*b=a*c\Rightarrow b=c$ (умножаем слева на $a^{-1}$); $(a^{-1})^{-1}=a$; $(a*b)^{-1}=b^{-1}*a^{-1}$; $a^n a^m=a^{n+m}$, $(a^n)^m=a^{nm}$; $\operatorname{ord}(a)=\operatorname{ord}(a^{-1})$.
- Приём: если $a*a=e$ для всех $a\in G$, то G абелева, так как $ab=(ab)^{-1}=b^{-1}a^{-1}=ba$.
- Примеры групп: $(\mathbb{Z},+)$; $(\mathbb{Z}_n,+)$ (вычеты по сложению, порядок $n$); $(\mathbb{Z}_p^*,\cdot)$ (ненулевые вычеты по простому модулю, порядок $p-1$); $(\mathbb{Z}_n^*,\cdot)$ (обратимые вычеты, порядок $\varphi(n)$); $(S_n,\circ)$ (все подстановки, порядок $n!$); $(GL_n(\mathbb{R}),\cdot)$ (обратимые матрицы); $(SL_n(\mathbb{R}),\cdot)$ (матрицы с определителем 1); $(\mathbb{R}^*,\cdot)$; группа поворотов правильного $n$-угольника (циклическая порядка $n$).
- Примеры, где аксиом не хватает: $(\mathbb{Z},\cdot)$ только моноид (обратимы лишь $\pm1$); $(\mathbb{Z}_n,\cdot)$ моноид, не группа при $n>1$ (нуль необратим); $(\Sigma^*,\cdot)$ слова с конкатенацией и пустым словом, моноид; $(2^M,\cup)$ идемпотентный моноид.
- Кольца и поля: $\mathbb{Z}$, $\mathbb{Z}_n$, $\mathbb{Z}[x]$, $\mathbb{R}[x]$ это кольца; $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{C}$ поля; $\mathbb{Z}_p$ поле при простом p; $\mathbb{Z}_n$ при составном n имеет делители нуля и полем не является. Некоммутативное кольцо, в котором все ненулевые элементы обратимы, называют телом (пример: кватернионы).

**Пример**: $G=\mathbb{Z}_6=\{0,1,2,3,4,5\}$ по сложению, $|G|=6$. Порядки: $\operatorname{ord}(0)=1$, $\operatorname{ord}(1)=6$, $\operatorname{ord}(2)=3$ (так как $2+2+2=0$), $\operatorname{ord}(3)=2$, $\operatorname{ord}(4)=3$, $\operatorname{ord}(5)=6$. Все порядки делят $|G|=6$ (это теорема Лагранжа из вопроса 9). Мультипликативный пример: $\mathbb{Z}_9^*=\{1,2,4,5,7,8\}$, порядок $\varphi(9)=6$; степени двойки: $2,4,8,7,5,1$, значит $\operatorname{ord}(2)=6$, элемент 2 порождает всю группу. Негруппа: $\mathbb{Z}_6$ по умножению, элемент 2 необратим, так как $2x\equiv1\pmod6$ решений не имеет (НОД(2,6)=2 не делит 1).

**Что спросит экзаменатор**:
- Чем моноид отличается от группы? У моноида есть нейтральный, но нет требования обратных; группа это моноид с обратными.
- Единственны ли нейтральный и обратный элементы? Да: если $e_1,e_2$ нейтральные, то $e_1=e_1e_2=e_2$; если $b,c$ обратные к $a$, то $b=b(ac)=(ba)c=c$.
- Приведите неабелеву группу. $(S_3,\circ)$: $(12)(13)=(132)$, а $(13)(12)=(123)$, результаты разные.
- Почему $\mathbb{Z}_n$ по умножению не группа? Нуль и делители нуля необратимы; обратимы ровно вычеты с НОД(k,n)=1, и они образуют группу $\mathbb{Z}_n^*$ порядка $\varphi(n)$.

## Вопрос 9. Группы подстановок, теорема Кэли. Числа Стирлинга первого рода.

**Суть на пальцах**: Подгруппа это «маленькая группа внутри большой» с той же операцией. Лагранж утверждает, что подгруппа укладывается в группу целое число раз, потому что сдвиги подгруппы дают одинаковые по размеру куски, которые не пересекаются и вместе покрывают всю группу. Отсюда ключевой практический факт: порядок любого элемента делит порядок группы, то есть $a^{|G|}=e$. Это прямой предок малой теоремы Ферма $a^{p-1}\equiv1\pmod p$ и теоремы Эйлера $a^{\varphi(n)}\equiv1$, на которых стоят RSA и вероятностные тесты простоты.

**Определения**:
- Подгруппа: непустое $H\subseteq G$ называется подгруппой ($H\le G$), если H замкнуто относительно операции группы G и само образует группу с этой же операцией.
- Собственная подгруппа: $H\ne G$. Нетривиальная: $H\ne\{e\}$. Тривиальные подгруппы: $\{e\}$ и сама G.
- Левый смежный класс по H: $aH=\{ah:h\in H\}$. Правый: $Ha=\{ha:h\in H\}$. В абелевой группе $aH=Ha$.
- Индекс подгруппы $[G:H]$: число различных левых смежных классов.
- Подгруппа, порождённая элементом $a$: $\langle a\rangle=\{a^k:k\in\mathbb{Z}\}$; её порядок равен $\operatorname{ord}(a)$. В аддитивной записи $\langle a\rangle=\{ka\}$.
- Подгруппа, порождённая подмножеством: наименьшая подгруппа, содержащая это подмножество.

**Теоремы и формулы**:
- Критерий подгруппы: непустое $H\subseteq G$ есть подгруппа $\Leftrightarrow$ для любых $a,b\in H$ выполнено $ab^{-1}\in H$. Обоснование одного условия: при $b=a$ получаем $e=aa^{-1}\in H$; при $a=e$ получаем $b^{-1}\in H$; тогда $ab=a(b^{-1})^{-1}\in H$, то есть H замкнуто и содержит обратные. Для конечного H достаточно проверить замкнутость относительно операции.
- Теорема Лагранжа: если G конечна и $H\le G$, то
$$|G|=|H|\cdot[G:H],$$
в частности $|H|$ делит $|G|$.
- Скелет доказательства:
  1. Введём на G отношение $a\sim b\Leftrightarrow a^{-1}b\in H$ (эквивалентно $b\in aH$, то есть $aH=bH$); это отношение эквивалентности, значит G разбита на непересекающиеся классы $aH$.
  2. Классы либо совпадают, либо не пересекаются: если $ah_1=bh_2$, то $a=bh_2h_1^{-1}$ и для любого $h$ имеем $ah=b(h_2h_1^{-1}h)\in bH$, то есть $aH\subseteq bH$, и симметрично $bH\subseteq aH$.
  3. Объединение всех классов есть G, так как $a\in aH$ (ведь $e\in H$).
  4. Все классы одного размера: $h\mapsto ah$ это биекция $H\to aH$ с обратным отображением $x\mapsto a^{-1}x$, значит $|aH|=|H|$.
  5. Итого G состоит из $[G:H]$ классов по $|H|$ элементов: $|G|=|H|\cdot[G:H]$.
- Следствия:
  1. Порядок элемента делит порядок группы: $\operatorname{ord}(a)\mid|G|$ (Лагранж для $H=\langle a\rangle$).
  2. $a^{|G|}=e$ для любого $a\in G$.
  3. Малая теорема Ферма: при простом p и $p\nmid a$ верно $a^{p-1}\equiv1\pmod p$. Доказательство: $|\mathbb{Z}_p^*|=p-1$, элемент a лежит в этой группе, значит его порядок делит $p-1$.
  4. Теорема Эйлера: если НОД$(a,n)=1$, то $a^{\varphi(n)}\equiv1\pmod n$ (Лагранж в группе $\mathbb{Z}_n^*$ порядка $\varphi(n)$).
  5. Группа простого порядка циклическая: если $|G|=p$ простое и $a\ne e$, то $\operatorname{ord}(a)$ делит p и больше единицы, значит равен p, поэтому $G=\langle a\rangle$.
  6. Обратное к теореме Лагранжа неверно: делимость $d\mid|G|$ не гарантирует подгруппу порядка d. Контрпример: $A_4$ имеет порядок 12, но подгруппы порядка 6 в ней нет. Для конечных абелевых групп обратное верно: подгруппа любого порядка d, делящего $|G|$, существует.
  7. Формула произведения подгрупп: $|HK|=\dfrac{|H|\cdot|K|}{|H\cap K|}$.
  8. Подгруппа индекса 2 нормальна.

**Пример**: $G=\mathbb{Z}_{12}$ по сложению, $|G|=12$. Возьмём $H=\langle3\rangle=\{0,3,6,9\}$, тогда $|H|=4$ и индекс $[G:H]=3$, проверка Лагранжа: $4\cdot3=12$. Порядки элементов по порядку $0,1,\dots,11$: $1,12,6,4,3,12,2,12,3,4,6,12$, то есть $\operatorname{ord}(1)=\operatorname{ord}(5)=\operatorname{ord}(7)=\operatorname{ord}(11)=12$, $\operatorname{ord}(2)=\operatorname{ord}(10)=6$, $\operatorname{ord}(3)=\operatorname{ord}(9)=4$, $\operatorname{ord}(4)=\operatorname{ord}(8)=3$, $\operatorname{ord}(6)=2$, $\operatorname{ord}(0)=1$; все эти числа делят 12. Проверка $a^{12}=e$ в аддитивной записи: $12a\equiv0\pmod{12}$ верно для всех a. Дополнительно элементы порядка 3 это 4 и 8, их ровно $\varphi(3)=2$ (общая формула из вопроса 11).

**Что спросит экзаменатор**:
- Почему смежные классы не пересекаются и одинаковы по размеру? Не пересекаются по пункту 2 доказательства, одинаковы по биекции $h\mapsto ah$.
- Как вывести малую теорему Ферма из Лагранжа? Применить Лагранжа к группе $\mathbb{Z}_p^*$ порядка $p-1$ и заметить, что $\operatorname{ord}(a)$ делит $p-1$.
- Верно ли обратное к Лагранжу? Нет, контрпример $A_4$ порядка 12 без подгруппы порядка 6.
- Сколько подгрупп у циклической группы порядка n? Ровно $\tau(n)$, число делителей n, по одной подгруппе каждого порядка $d\mid n$.

## Вопрос 10. Циклические группы, подсчёт числа образующих этих групп.

**Суть на пальцах**: Подстановка степени n это перестановка чисел $1,\dots,n$, записанная таблицей из двух строк. Подстановки образуют группу $S_n$ порядка $n!$. Любая подстановка распадается на независимые циклы, и её порядок равен НОК длин циклов (тот же НОК, что и в CRT-арифметике; в крипто это ровно вычисление порядка элемента и порядок подгруппы в циклической группе). Теорема Кэли говорит, что других конечных групп, кроме подгрупп $S_n$, не бывает: абстрактные аксиомы группы ничего не добавляют к перестановкам. В крипто подстановки это S-боксы в блочных шифрах и perm-слои в сетях.

**Определения**:
- Подстановка степени n: биекция $\sigma:\{1,2,\dots,n\}\to\{1,2,\dots,n\}$, запись
$$\sigma=\begin{pmatrix}1&2&\cdots&n\\ \sigma(1)&\sigma(2)&\cdots&\sigma(n)\end{pmatrix}.$$
- Умножение подстановок: $(\sigma\tau)(i)=\sigma(\tau(i))$ (сначала действует $\tau$, затем $\sigma$). Множество всех подстановок степени n с этим умножением есть группа $S_n$, порядок $n!$, нейтральный элемент это тождественная подстановка $e$.
- Цикл $(i_1i_2\dots i_k)$: подстановка с $i_1\to i_2\to\dots\to i_k\to i_1$, остальные элементы неподвижны. Длина цикла k; цикл длины 2 называется транспозицией.
- Циклы независимы (не пересекаются), если множества их элементов не пересекаются.
- Неподвижная точка подстановки $\sigma$: $i$ с $\sigma(i)=i$; такие точки это циклы длины 1, при записи циклами их обычно опускают.
- Группа подстановок: любая подгруппа $S_n$. Знакопеременная группа $A_n$: множество всех чётных подстановок.
- Знак подстановки: $\operatorname{sgn}(\sigma)=(-1)^{N(\sigma)}$, где $N(\sigma)$ число инверсий пары $(i,j)$ с $i<j$ и $\sigma(i)>\sigma(j)$; отображение $\operatorname{sgn}:S_n\to\{1,-1\}$ есть гомоморфизм, его ядро это $A_n$; подстановки со знаком $+1$ чётные, со знаком $-1$ нечётные.
- Циклический тип (структура) подстановки: набор длин её независимых циклов.

**Теоремы и формулы**:
- Разложение в циклы: каждая подстановка единственным образом (с точностью до порядка сомножителей) представима в виде произведения независимых циклов; сумма длин циклов равна n, если учитывать и неподвижные точки.
- Порядок подстановки: $\operatorname{ord}(\sigma)=\text{НОК}(k_1,\dots,k_m)$, где $k_i$ это длины независимых циклов. Причина: на цикле длины $k$ нужно $k$ применений, чтобы все элементы вернулись, а циклы действуют на разных элементах независимо.
- Знак: если в разложении с неподвижными точками ровно m циклов, то $\operatorname{sgn}(\sigma)=(-1)^{n-m}$; цикл длины k имеет знак $(-1)^{k-1}$; транспозиция меняет знак.
- $|A_n|=n!/2$ при $n\ge2$, $[S_n:A_n]=2$, поэтому $A_n$ нормальна в $S_n$.
- Транспозиции порождают $S_n$; цикл $(12\dots n)$ вместе с транспозицией $(12)$ тоже порождают $S_n$.
- Теорема Кэли: всякая конечная группа G порядка n изоморфна некоторой подгруппе группы $S_n$.
  - Скелет доказательства:
  1. Для каждого $g\in G$ определим левый сдвиг $L_g:G\to G$, $L_g(x)=gx$.
  2. $L_g$ биекция (обратное отображение $L_{g^{-1}}$), значит $L_g$ элемент группы $S(G)$ всех биекций множества G на себя, а $S(G)\cong S_n$.
  3. Отображение $\Phi:G\to S(G)$, $\Phi(g)=L_g$, есть гомоморфизм: $L_{gh}(x)=ghx=L_g(L_h(x))$, то есть $L_{gh}=L_g\circ L_h$.
  4. Ядро тривиально: если $L_g=\mathrm{id}$, то $gx=x$ для всех $x\in G$, в частности при $x=e$ получаем $g=e$.
  5. Значит $\Phi$ инъективен и $G\cong\Phi(G)\le S(G)\cong S_n$, то есть G изоморфна подгруппе $S_n$. Отображение $\Phi$ называют левым регулярным представлением.
  6. Замечание: оценка n не всегда минимальна, например $C_6\cong\langle(123)(45)\rangle\le S_5$ (подстановка $(123)(45)$ имеет порядок $\text{НОК}(3,2)=6$).
- Числа Стирлинга первого рода (беззнаковые) $\left[{n\atop k}\right]$: число подстановок степени n, имеющих ровно k циклов (неподвижные точки считаются циклами длины 1).
- Рекуррентность:
$$\left[{n\atop k}\right]=\left[{n-1\atop k-1}\right]+(n-1)\left[{n-1\atop k}\right].$$
  Обоснование: берём подстановку на $n-1$ элементе и добавляем элемент n. Либо n образует отдельный цикл $(n)$, тогда из $k-1$ циклов выходит k (первое слагаемое), либо n вставляется в существующий цикл сразу за любым из $n-1$ элементов, число циклов при этом не меняется (второе слагаемое).
- Краевые значения и сумма: $\left[{n\atop1}\right]=(n-1)!$ (циклов ровно один, это цикл длины n, а таких подстановок $(n-1)!$), $\left[{n\atop n}\right]=1$, $\left[{n\atop0}\right]=0$ при $n\ge1$ и
$$\sum_{k=1}^{n}\left[{n\atop k}\right]=n!.$$
- Малые значения (строки для $n=1,2,3,4,5$): $1$; $1,1$; $2,3,1$; $6,11,6,1$; $24,50,35,10,1$.
- Производящие функции: $x(x+1)(x+2)\cdots(x+n-1)=\sum_k\left[{n\atop k}\right]x^k$; знаковая версия $s(n,k)=(-1)^{n-k}\left[{n\atop k}\right]$ даёт $x(x-1)\cdots(x-n+1)=\sum_k s(n,k)x^k$.

**Пример**: $\sigma=(1234)(56)\in S_6$. Порядок равен $\text{НОК}(4,2)=4$: проверка $\sigma^2=(13)(24)$, $\sigma^4=e$. Неподвижных точек нет, циклов m=2, значит $\operatorname{sgn}=(-1)^{6-2}=+1$, подстановка чётная; то же даёт разложение в транспозиции: $(1234)(56)$ это $3+1=4$ транспозиции, а число 4 чётное. Числа Стирлинга: $\left[{4\atop2}\right]=11$, проверим перебором в $S_4$: двойных транспозиций 3 ($(12)(34)$, $(13)(24)$, $(14)(23)$), тройных циклов 8 (4 набора элементов по 3, по 2 направления обхода), итого $3+8=11$. Далее $\left[{4\atop1}\right]=3!=6$ (четырёхциклы), $\left[{4\atop4}\right]=1$, сумма $6+11+6+1=24=4!$.

**Что спросит экзаменатор**:
- Почему порядок подстановки равен НОК длин циклов, а не их произведению? Циклы действуют на непересекающихся множествах одновременно, поэтому нужно время, кратное каждой длине, например $(1234)(56)$ имеет порядок 4, а не 8.
- Как знак вычисляется по разложению в циклы? $\operatorname{sgn}=(-1)^{n-m}$, где m число циклов с учётом неподвижных точек; цикл длины k даёт $(-1)^{k-1}$.
- Идея доказательства теоремы Кэли? Левые сдвиги, они биекции, отображение в них гомоморфизм с тривиальным ядром, значит вложение в $S_n$.
- Чему равна сумма чисел Стирлинга первого рода по k? $n!$, так как это разбиение всех $n!$ подстановок по числу циклов; отсюда и рекуррентность.

## Вопрос 11. Прямая сумма групп (подгрупп). Примеры.

**Суть на пальцах**: Циклическая группа целиком порождается степенями одного элемента: $G=\langle g\rangle=\{e,g,g^2,\dots\}$. Устроены они проще всего: структура полностью описывается порядком n, но именно из них собирается вся классификация конечных абелевых групп (вопрос 12). В крипто это основной рабочий инструмент: в протоколе Диффи и Хеллмана берут образующую циклической группы $\mathbb{Z}_p^*$ или циклической подгруппы точек кривой, а стойкость держится на трудности дискретного логарифма. Знание числа образующих $\varphi(n)$ нужно, чтобы не выбрать генератор малого порядка (это убивает схему).

**Определения**:
- Группа G называется циклической, если существует $g\in G$ с $G=\langle g\rangle=\{g^k:k\in\mathbb{Z}\}$; такой элемент g называется образующей (порождающим).
- Порядок элемента: наименьшее натуральное $m$ с $g^m=e$; если такого $m$ нет, порядок бесконечен. В конечной группе $\operatorname{ord}(g)=|\langle g\rangle|$.
- Показатель (экспонента) группы: наименьшее $N$ с $a^N=e$ для всех $a\in G$.

**Теоремы и формулы**:
- Всякая циклическая группа абелева: $g^k g^m=g^{k+m}=g^m g^k$.
- Всякая подгруппа циклической группы циклическая. Идея: если $H\le\langle g\rangle$ и $H\ne\{e\}$, берём наименьшее $k>0$ с $g^k\in H$, тогда $H=\langle g^k\rangle$ (деление с остатком: $m=qk+r$, $g^r=g^m(g^k)^{-q}\in H$, а $0\le r<k$ даёт $r=0$).
- Конечная циклическая группа порядка n изоморфна $(\mathbb{Z}_n,+)$, изоморфизм $g^k\mapsto k$; бесконечная циклическая группа изоморфна $(\mathbb{Z},+)$. Обратно, $\mathbb{Z}_n$ циклическая с образующей 1.
- Порядок элемента в циклической группе порядка n:
$$\operatorname{ord}(g^k)=\frac{n}{\gcd(n,k)}.$$
- Число образующих: циклическая группа порядка n имеет ровно $\varphi(n)$ образующих.
- Доказательство (число образующих):
  1. Все элементы $\langle g\rangle$ это $g^0,g^1,\dots,g^{n-1}$, и порядок подгруппы $\langle g^k\rangle$ равен $\operatorname{ord}(g^k)$;
  2. $\langle g^k\rangle=G$ $\Leftrightarrow$ $\operatorname{ord}(g^k)=n$;
  3. по формуле порядка $\operatorname{ord}(g^k)=n/\gcd(n,k)=n$ $\Leftrightarrow$ $\gcd(n,k)=1$;
  4. количество таких k среди $1,\dots,n$ равно $\varphi(n)$ по определению функции Эйлера;
  5. значит ровно $\varphi(n)$ элементов порождают всю группу, остальные порождают собственные подгруппы.
- Подгруппы $\mathbb{Z}_n$: для каждого делителя $d\mid n$ существует ровно одна подгруппа порядка d, а именно $\langle n/d\rangle$; других подгрупп нет. Значит всего подгрупп $\tau(n)$ (число делителей n), все они циклические.
- Элемент порядка d в $\mathbb{Z}_n$ существует $\Leftrightarrow$ $d\mid n$; число элементов порядка d равно $\varphi(d)$. Обоснование: подгруппа порядка d в $\mathbb{Z}_n$ ровно одна, она циклическая, значит элементов порядка d в ней $\varphi(d)$; при этом $\sum_{d\mid n}\varphi(d)=n$, так что все элементы распределяются по порядкам без остатка.
- Критерий цикличности конечной группы G порядка n: равносильны условия
  - G циклическая, то есть существует элемент порядка n;
  - для каждого $d\mid n$ в G не более одной подгруппы порядка d;
  - для каждого $d\mid n$ число элементов порядка d не превосходит $\varphi(d)$ (тогда, ввиду $\sum_{d\mid n}\varphi(d)=n$, оно равно $\varphi(d)$ для каждого d).
- $\mathbb{Z}_p^*$ циклическая при любом простом p (мультипликативная группа конечного поля циклическая), порядок $p-1$. Группа $\mathbb{Z}_n^*$ циклическая не всегда: критерий $n\in\{1,2,4,p^k,2p^k\}$ для нечётного простого p и $k\ge1$. Контрпример: $\mathbb{Z}_8^*=\{1,3,5,7\}$, все элементы порядка 1 или 2, это $\mathbb{Z}_2\oplus\mathbb{Z}_2$, не циклическая.
- Для крипто: множество квадратичных вычетов есть подгруппа индекса 2 в $\mathbb{Z}_p^*$, значит имеет порядок $(p-1)/2$ и циклическая.

**Пример**: $\mathbb{Z}_{20}$: порядок элемента k равен $20/\gcd(20,k)$. Образующие это k с НОД$(k,20)=1$: $1,3,7,9,11,13,17,19$, их 8, и действительно $\varphi(20)=20\cdot\frac12\cdot\frac45=8$. Отдельные порядки: $\operatorname{ord}(1)=20$, $\operatorname{ord}(2)=10$, $\operatorname{ord}(4)=5$, $\operatorname{ord}(5)=4$, $\operatorname{ord}(10)=2$, $\operatorname{ord}(0)=1$. Распределение по порядкам: $8=\varphi(20)$ порядка 20, $4=\varphi(10)$ порядка 10 (это 2, 6, 14, 18), $4=\varphi(5)$ порядка 5 (это 4, 8, 12, 16), $2=\varphi(4)$ порядка 4 (это 5, 15), один элемент порядка 2 (это 10) и один порядка 1 (нуль), сумма $8+4+4+2+1+1=20$. Подгруппы по одной на каждый делитель: порядков 1, 2, 4, 5, 10, 20. Второй пример: $\mathbb{Z}_7^*$ порядка 6, её образующие это 3 и 5 (их $\varphi(6)=2$), а элемент 2 имеет порядок 3, так как $2^3=8\equiv1\pmod7$.

**Что спросит экзаменатор**:
- Почему образующих ровно $\varphi(n)$? Через формулу $\operatorname{ord}(g^k)=n/\gcd(n,k)$: образующая тогда и только тогда, когда НОД$(k,n)=1$, таких k ровно $\varphi(n)$.
- Как найти порядок элемента в $\mathbb{Z}_n$? Как $n/\gcd(n,k)$; например в $\mathbb{Z}_{20}$ элемент 4 имеет порядок $20/4=5$.
- Любая ли подгруппа циклической группы циклическая? Да, берём наименьшую положительную степень, попавшую в подгруппу.
- Циклическая ли $\mathbb{Z}_8^*$? Нет, порядок 4, но все элементы порядка не выше 2, группа изоморфна $\mathbb{Z}_2\oplus\mathbb{Z}_2$. А $\mathbb{Z}_7^*$ циклическая порядка 6.

## Вопрос 12. Примарные циклические группы и их свойства. Теорема о строении конечных абелевых групп.

**Суть на пальцах**: Прямая сумма это покоординатное соединение групп: элемент это набор координат, операции идут покоординатно. Абелеву группу можно разобрать на простейшие детали, примарные циклические группы, примерно как число раскладывают на простые множители, и набор деталей однозначен. Поэтому по порядку и разложению группы видно всё: циклическая она или нет, сколько в ней элементов каждого порядка. В крипто это ровно китайская теорема об остатках: $\mathbb{Z}_n$ распадается в сумму $\mathbb{Z}_{p_i^{k_i}}$, поэтому RSA считает по простым модулям быстрее, а схемы разделения секрета восстанавливают секрет по частям.

**Определения**:
- Внешняя прямая сумма (прямое произведение) групп $G_1,\dots,G_k$: множество $G_1\times\cdots\times G_k$ с покоординатной операцией
$$(g_1,\dots,g_k)(h_1,\dots,h_k)=(g_1h_1,\dots,g_kh_k).$$
  Обозначение $G_1\oplus\cdots\oplus G_k$ (для абелевых групп) или $G_1\times\cdots\times G_k$. Порядок равен $\prod_i|G_i|$, сумма абелева тогда и только тогда, когда абелевы все слагаемые, а порядок элемента равен $\text{НОК}(\operatorname{ord}(g_1),\dots,\operatorname{ord}(g_k))$.
- Внутренняя прямая сумма: группа G разложена в прямую сумму подгрупп $H_1,\dots,H_k$ ($G=H_1\oplus\cdots\oplus H_k$), если (1) $G=H_1H_2\cdots H_k$, то есть каждый элемент есть произведение $h_1\cdots h_k$, (2) $H_i\cap(H_1\cdots H_{i-1}H_{i+1}\cdots H_k)=\{e\}$ для каждого i, (3) все $H_i$ нормальны в G. Равносильно: каждый элемент G единственным образом записывается в виде $h_1h_2\cdots h_k$ с $h_i\in H_i$.
- В абелевом случае условия проще: $G=H_1+\cdots+H_k$ и $H_i\cap\sum_{j\ne i}H_j=\{0\}$. Для двух подгрупп: $G=H\oplus K$ $\Leftrightarrow$ $|H||K|=|G|$ и $H\cap K=\{0\}$ (при этом $H,K$ автоматически нормальны).
- Примарная группа (p-группа): конечная группа, порядок которой есть степень простого числа p (равносильно: порядок каждого элемента есть степень p). Примарная циклическая группа: $\mathbb{Z}_{p^k}$, её порядок $p^k$.
- Инвариантные множители группы A: разложение $A\cong\mathbb{Z}_{d_1}\oplus\cdots\oplus\mathbb{Z}_{d_r}$, где $d_i>1$ и $d_1\mid d_2\mid\cdots\mid d_r$. Набор $d_i$ определён однозначно, $|A|=d_1\cdots d_r$, а $d_r$ это показатель (экспонента) группы.
- Элементарные делители: набор порядков $p^{k}$ примарных циклических слагаемых в примарном разложении.

**Теоремы и формулы**:
- Критерий: $\mathbb{Z}_m\oplus\mathbb{Z}_n\cong\mathbb{Z}_{mn}$ $\Leftrightarrow$ НОД$(m,n)=1$.
  - Скелет доказательства:
  1. Порядок элемента $(a,b)$ в $\mathbb{Z}_m\oplus\mathbb{Z}_n$ равен $\text{НОК}(\operatorname{ord}a,\operatorname{ord}b)$, поэтому максимальный порядок элемента равен $\text{НОК}(m,n)$.
  2. Если НОД$(m,n)=1$, то $\text{НОК}(m,n)=mn$ и элемент $(1,1)$ имеет порядок $mn=|G|$, значит он образующая, группа циклическая порядка mn, то есть $\cong\mathbb{Z}_{mn}$.
  3. Если НОД$(m,n)=d>1$, то $\text{НОК}(m,n)=mn/d<mn$: в $\mathbb{Z}_m\oplus\mathbb{Z}_n$ элемента порядка mn нет, а в $\mathbb{Z}_{mn}$ такой элемент есть (например 1), значит группы не изоморфны.
  - Обобщение: если $n_1,\dots,n_k$ попарно взаимно просты, то $\mathbb{Z}_{n_1}\oplus\cdots\oplus\mathbb{Z}_{n_k}\cong\mathbb{Z}_{n_1\cdots n_k}$.
- Китайская теорема об остатках: если $n=p_1^{k_1}\cdots p_r^{k_r}$ (различные простые), то $\mathbb{Z}_n\cong\mathbb{Z}_{p_1^{k_1}}\oplus\cdots\oplus\mathbb{Z}_{p_r^{k_r}}$.
- Свойства примарной циклической группы $\mathbb{Z}_{p^k}$:
  1. порядок $p^k$;
  2. для каждого $i=0,1,\dots,k$ ровно одна подгруппа порядка $p^i$, а именно $\langle p^{k-i}\rangle$; это все подгруппы, и они образуют цепочку $\{0\}\subset\langle p^{k-1}\rangle\subset\langle p^{k-2}\rangle\subset\cdots\subset\mathbb{Z}_{p^k}$;
  3. число элементов порядка $p^i$ равно $\varphi(p^i)=p^i-p^{i-1}$ при $i\ge1$;
  4. каждая подгруппа и каждая факторгруппа циклической группы циклические.
- Теорема о строении конечных абелевых групп: любая конечная абелева группа A разлагается в прямую сумму примарных циклических групп,
$$A\cong\mathbb{Z}_{p_1^{k_1}}\oplus\mathbb{Z}_{p_2^{k_2}}\oplus\cdots\oplus\mathbb{Z}_{p_s^{k_s}},$$
  и это разложение единственно с точностью до порядка слагаемых (однозначен набор порядков $p_i^{k_i}$). Равносильная форма: $A\cong\mathbb{Z}_{d_1}\oplus\cdots\oplus\mathbb{Z}_{d_r}$ с $d_1\mid d_2\mid\cdots\mid d_r$, инвариантные множители определены однозначно.
- Следствия: A циклическая $\Leftrightarrow$ в инвариантной форме $r=1$ $\Leftrightarrow$ в примарном разложении для каждого простого p не более одного слагаемого. A есть прямая сумма своих силовских p-подгрупп (компонента по каждому простому p единственна).
- Переход от примарного разложения к инвариантным множителям: для каждого простого p выписать порядки его слагаемых по невозрастанию; выровнять списки по длине, дополнив слева единицами; перемножить элементы каждого столбца; полученные произведения, упорядоченные по возрастанию, это и есть $d_1\mid d_2\mid\cdots\mid d_r$.
- Число абелевых групп порядка $n=p_1^{k_1}\cdots p_r^{k_r}$ равно $P(k_1)\cdots P(k_r)$, где $P$ это число разбиений натурального числа на слагаемые: $P(1)=1$, $P(2)=2$, $P(3)=3$, $P(4)=5$.

**Пример**: возьмём $G=\mathbb{Z}_4\oplus\mathbb{Z}_2\oplus\mathbb{Z}_3\oplus\mathbb{Z}_3$, её порядок $72=2^3\cdot3^2$. Примарное разложение: по простому 2 слагаемые порядков 4 и 2, по простому 3 порядков 3 и 3. Собираем столбцы (в первый берём наибольшее слагаемое каждого простого): $(4,3)$ и $(2,3)$; перемножаем внутри столбцов: $d_2=4\cdot3=12$, $d_1=2\cdot3=6$, значит $G\cong\mathbb{Z}_6\oplus\mathbb{Z}_{12}$ (проверка: $6\mid12$, порядок $6\cdot12=72$). Циклической она не является, так как слагаемых два.
Все абелевы группы порядка 72, их ровно 6 (разбиений числа 3 три: $3$, $2+1$, $1+1+1$; разбиений числа 2 два: $2$ и $1+1$; итого $3\cdot2=6$): $\mathbb{Z}_{72}$; $\mathbb{Z}_3\oplus\mathbb{Z}_{24}$; $\mathbb{Z}_2\oplus\mathbb{Z}_{36}$; $\mathbb{Z}_6\oplus\mathbb{Z}_{12}$; $\mathbb{Z}_2\oplus\mathbb{Z}_2\oplus\mathbb{Z}_{18}$; $\mathbb{Z}_2\oplus\mathbb{Z}_6\oplus\mathbb{Z}_6$. Все шесть попарно неизоморфны, их показатели равны $72,24,36,12,18,6$ соответственно.
Ещё пример порядка $360=2^3\cdot3^2\cdot5$ (тоже 6 групп, так как $3\cdot2\cdot1=6$): $\mathbb{Z}_8\oplus\mathbb{Z}_9\oplus\mathbb{Z}_5\cong\mathbb{Z}_{360}$ (показатель 360, есть элемент порядка 360) и $\mathbb{Z}_2\oplus\mathbb{Z}_4\oplus\mathbb{Z}_9\oplus\mathbb{Z}_5\cong\mathbb{Z}_2\oplus\mathbb{Z}_{180}$ (показатель 180, элемента порядка 360 нет); эти группы неизоморфны.
Маленький пример критерия: $\mathbb{Z}_2\oplus\mathbb{Z}_3\cong\mathbb{Z}_6$, так как НОД$(2,3)=1$; но $\mathbb{Z}_2\oplus\mathbb{Z}_2$ не циклическая (все неединичные элементы порядка 2, порядка 4 нет), поэтому $\mathbb{Z}_2\oplus\mathbb{Z}_2\not\cong\mathbb{Z}_4$, хотя порядки совпадают.

**Что спросит экзаменатор**:
- Когда $\mathbb{Z}_m\oplus\mathbb{Z}_n$ циклическая? Тогда и только тогда, когда НОД$(m,n)=1$.
- Почему $\mathbb{Z}_2\oplus\mathbb{Z}_2$ не изоморфна $\mathbb{Z}_4$? В первой нет элемента порядка 4, показатель равен 2, во второй есть элемент порядка 4.
- Почему разложение единственно? Число элементов порядка $p^i$ в группе восстанавливается по самой группе, отсюда однозначно восстанавливается, сколько циклических слагаемых порядка $p^i$ она содержит.
- Как найти инвариантные множители? Разложить по простым, выровнять списки и перемножить столбцы; например $\mathbb{Z}_4\oplus\mathbb{Z}_2\oplus\mathbb{Z}_9\cong\mathbb{Z}_2\oplus\mathbb{Z}_{36}$.
- Сколько абелевых групп порядка 8? Три: $\mathbb{Z}_8$, $\mathbb{Z}_4\oplus\mathbb{Z}_2$, $\mathbb{Z}_2\oplus\mathbb{Z}_2\oplus\mathbb{Z}_2$.

## Шпаргалка блока

1. Группа: ассоциативность, нейтральный $e$, обратный $a^{-1}$. Абелева: плюс $ab=ba$.
2. Иерархия: полугруппа, моноид, группа, абелева группа. Кольцо: абелева группа по $+$, полугруппа по $\cdot$, дистрибутивность. Поле: коммутативное кольцо с единицей, все ненулевые обратимы.
3. $\mathbb{Z}_n$ поле $\Leftrightarrow$ n простое. В $\mathbb{Z}_n$ обратимы ровно вычеты с НОД$(k,n)=1$, их $\varphi(n)$, они дают группу $\mathbb{Z}_n^*$.
4. Примеры групп: $(\mathbb{Z},+)$, $(\mathbb{Z}_n,+)$, $(\mathbb{Z}_p^*,\cdot)$ порядка $p-1$, $S_n$ порядка $n!$, $GL_n(\mathbb{R})$, $SL_n(\mathbb{R})$.
5. $(ab)^{-1}=b^{-1}a^{-1}$; $\operatorname{ord}(a)=\operatorname{ord}(a^{-1})$; порядок элемента делит $|G|$.
6. Критерий подгруппы: непустое H подгруппа $\Leftrightarrow$ $ab^{-1}\in H$ для всех $a,b\in H$.
7. Лагранж: $|G|=|H|\cdot[G:H]$. Доказательство: классы $aH$ не пересекаются, равны по размеру, покрывают G.
8. Следствия: $a^{|G|}=e$; Ферма $a^{p-1}\equiv1\pmod p$; Эйлер $a^{\varphi(n)}\equiv1\pmod n$ при НОД$(a,n)=1$.
9. Группа простого порядка циклическая. Обратное к Лагранжу неверно: $A_4$ порядка 12 без подгруппы порядка 6.
10. Подстановка: таблица двух строк, $(\sigma\tau)(i)=\sigma(\tau(i))$, $|S_n|=n!$.
11. Цикл $(i_1\dots i_k)$; подстановка есть произведение независимых циклов; неподвижная точка это цикл длины 1.
12. Порядок подстановки равен НОК длин независимых циклов.
13. Знак: $\operatorname{sgn}=(-1)^{n-m}$ при m циклах (с неподвижными точками), $|A_n|=n!/2$.
14. Кэли: G порядка n вкладывается в $S_n$ через левые сдвиги $L_g(x)=gx$, ядро тривиально.
15. Стирлинг первого рода $\left[{n\atop k}\right]$: подстановки степени n ровно с k циклами; $\left[{n\atop k}\right]=\left[{n-1\atop k-1}\right]+(n-1)\left[{n-1\atop k}\right]$; сумма равна $n!$; строка $n=5$: $24,50,35,10,1$.
16. Циклическая группа $G=\langle g\rangle$; конечная порядка n изоморфна $\mathbb{Z}_n$; подгруппа циклической группы циклическая.
17. $\operatorname{ord}(g^k)=n/\gcd(n,k)$; образующих ровно $\varphi(n)$, это $g^k$ с НОД$(k,n)=1$.
18. В $\mathbb{Z}_n$ элементов порядка d ровно $\varphi(d)$ при $d\mid n$; подгрупп ровно $\tau(n)$, по одной каждого порядка.
19. $\mathbb{Z}_p^*$ циклическая порядка $p-1$; $\mathbb{Z}_n^*$ циклическая $\Leftrightarrow$ $n\in\{1,2,4,p^k,2p^k\}$; $\mathbb{Z}_8^*$ не циклическая.
20. Прямая сумма: покоординатные операции, $|G_1\oplus G_2|=|G_1||G_2|$, $\operatorname{ord}(g_1,g_2)=\text{НОК}(\operatorname{ord}g_1,\operatorname{ord}g_2)$.
21. $\mathbb{Z}_m\oplus\mathbb{Z}_n\cong\mathbb{Z}_{mn}$ $\Leftrightarrow$ НОД$(m,n)=1$; CRT: $\mathbb{Z}_n\cong\mathbb{Z}_{p_1^{k_1}}\oplus\cdots\oplus\mathbb{Z}_{p_r^{k_r}}$.
22. $\mathbb{Z}_2\oplus\mathbb{Z}_3\cong\mathbb{Z}_6$, но $\mathbb{Z}_2\oplus\mathbb{Z}_2\not\cong\mathbb{Z}_4$ (нет элемента порядка 4).
23. Примарная циклическая $\mathbb{Z}_{p^k}$: ровно одна подгруппа порядка $p^i$ при каждом $i\le k$; элементов порядка $p^i$ ровно $\varphi(p^i)$.
24. Строение: конечная абелева группа есть прямая сумма примарных циклических, разложение единственно с точностью до порядка слагаемых; инвариантная форма $d_1\mid d_2\mid\cdots\mid d_r$.
25. Абелева группа циклическая $\Leftrightarrow$ один инвариантный множитель; показатель равен наибольшему инвариантному множителю $d_r$.
26. Число абелевых групп порядка $p_1^{k_1}\cdots p_r^{k_r}$ равно произведению чисел разбиений $P(k_i)$.
27. Порядок 72, шесть групп: $\mathbb{Z}_{72}$, $\mathbb{Z}_3\oplus\mathbb{Z}_{24}$, $\mathbb{Z}_2\oplus\mathbb{Z}_{36}$, $\mathbb{Z}_6\oplus\mathbb{Z}_{12}$, $\mathbb{Z}_2\oplus\mathbb{Z}_2\oplus\mathbb{Z}_{18}$, $\mathbb{Z}_2\oplus\mathbb{Z}_6\oplus\mathbb{Z}_6$.
